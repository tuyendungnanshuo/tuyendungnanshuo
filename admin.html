Còn 1 bước để bật Admin

Mở file config.js và điền Supabase Project URL cùng Publishable/Anon key. Sau đó tải file lên GitHub lại.

window.NANSHUO_CONFIG = {
  supabaseUrl: "https://xxxx.supabase.co",
  supabaseKey: "sb_publishable_..."
};

Không bao giờ dùng service_role key ở đây.
